## От снимка до композиции

| Задача | Что есть в Photon |
|---|---|
| Собрать изображение | Слои и группы, режимы наложения, маски и обтравочные маски, трансформация и эффекты слоёв. |
| Убрать лишнее | Кисть, ластик, штамп, восстановление, выделения и заливка с учётом содержимого. |
| Настроить цвет | Кривые, уровни, цветовой баланс, экспозиция, HSL, градиентные карты и Camera Raw. |
| Добавить идею | Редактируемый текст, фигуры, градиенты, направляющие и привязки. |
| Отделить объект | Выделение объекта и удаление фона с локальными моделями. |
| Сохранить результат | Проекты `.comp`, импорт изображений и RAW, импорт PSD/PSB, экспорт PNG с прозрачностью и JPEG с предпросмотром качества. |

Обработка изображений и модели работают на вашем компьютере. Интернет нужен для проверки обновлений, их загрузки и отправки выбранных вами отчётов об ошибках.

## Установка

Откройте **[последний выпуск](https://github.com/epem/Photon/releases/latest)** и выберите файл в разделе **Assets**:

| Файл | Как использовать |
|---|---|
| `Photon-Windows-x64-….msi` | Мастер установки с ярлыком в меню «Пуск». С 0.1.9 — оформление Photon, EULA RU/EN и выбор папки. |
| `Photon-Windows-x64-….zip` | Распакуйте **всю** папку и запустите `Photon.exe`. Установка не нужна. |
| `….sha256` | Контрольная сумма соответствующего пакета. Для запуска не требуется. |

Сборка для **Windows x64**, проверяется на Windows 11. Среда .NET и необходимые библиотеки включены. Для ARM64 и 32-разрядной Windows отдельных сборок пока нет.

В установщике 0.1.9 можно оставить предложенный каталог или нажать **Обзор** и выбрать свой; следующие обновления запоминают этот путь. Обложка Photon встречает вас в начале и в конце установки, а ссылка **Канал NRG · t.me/nrgit** ведёт в наше комьюнити.

**`Source code (zip)` и `Source code (tar.gz)` — не установщики.** Эти ссылки GitHub добавляет автоматически. В этом репозитории находятся описание, иллюстрации и шаблон багрепорта; исходный код приложения здесь не публикуется.

## Первые пять минут

1. Создайте холст или импортируйте изображение. Перетащите файл **на полосу вкладок**, чтобы открыть отдельный документ; **на холст**, чтобы добавить слой.
2. Разложите композицию по слоям. Маска позволяет скрыть часть слоя, сохранив исходные пиксели.
3. Настройте цвет и детали. Перед применением сравните результат в предпросмотре.
4. Сохраните работу как проект `.comp`, а готовую картинку экспортируйте в PNG или JPEG.

Папка `.comp` — это весь проект. Храните и переносите её целиком.

## Под себя

**Правка → Настройки / Edit → Settings**: русский или английский язык, горячие клавиши, ширина панели слоёв, сетка, направляющие, привязки, качество JPEG и автоматическая проверка обновлений. Язык можно посмотреть сразу; «Отмена» возвращает прежние настройки.

| Действие | По умолчанию |
|---|---|
| Кисть / ластик | `B` / `E` |
| Перемещение / трансформация | `V` / `Ctrl+T` |
| Отменить / повторить | `Ctrl+Z` / `Ctrl+Shift+Z` |
| Вписать холст / масштаб 100% | `Ctrl+0` / `Ctrl+1` |
| Панорамирование | Удерживать `Пробел` |
| Размер кисти | `[` / `]` |

Полный список и переназначение доступны в **Горячих клавишах**. Числовые поля и ползунки реагируют на колесо мыши; `Shift` увеличивает шаг.

## Заметили баг?

**Отправка отчётов прямо из программы доступна с Windows-сборки 0.1.8.** Откройте **Справка → Сообщить об ошибке / Help → Report a Bug**.

1. Коротко назовите проблему и напишите шаги, после которых она возникает.
2. По желанию включите скриншот. Photon покажет снимок **только окна редактора** — проверьте его перед отправкой. По умолчанию снимок выключен.
3. Нажмите **Отправить отчёт**. Текст, технические данные и выбранный снимок отправятся вместе. Аккаунт GitHub не нужен.
4. После подтверждения нажмите **Открыть обращение**, чтобы увидеть отчёт на GitHub.

**Обращения и вложения публичные.** В диагностику входят версия Photon и Windows, выбранный инструмент, размер холста и число слоёв. На снимке могут быть видны ваши изображения — не включайте личные данные, которые не хотите публиковать. Cloudflare передаёт отчёт в GitHub без собственного архива; обращение и снимок остаются на GitHub.

Если связь оборвалась, используйте **Проверить статус**: Photon проверит прежнее обращение. Черновик сохраняется при закрытии формы, пока открыт этот редактор; после выхода из программы он не сохраняется.

В предыдущей форме с кнопкой **Открыть GitHub** публикацию нужно подтвердить в браузере; для неё требуется аккаунт GitHub. Раздел **Другие способы отправки** позволяет открыть форму GitHub или скопировать текст; снимок можно сохранить в PNG рядом с предпросмотром. Если программа не запускается или в ней ещё нет формы отчёта, **[создайте обращение напрямую](https://github.com/epem/Photon/issues/new?template=bug_report.md)**.

При зависании укажите размер холста, количество слоёв, выбранный инструмент и действие, которое тормозит. Не прикладывайте личные изображения или проекты, если не хотите их публиковать.

## Обновления и текущие ограничения

**Справка → Проверить обновления** проверяет стабильные релизы этого репозитория. Photon сверяет SHA-256 скачанного файла и предлагает сохранить проекты перед запуском установщика. ZIP-версию распаковывайте в отдельную папку. Встроенные обновления доступны начиная с 0.1.6.

Photon активно развивается. PSD/PSB — импорт с ограничениями, прежде всего для 8-битных RGB-документов; полное совпадение со всеми возможностями Photoshop не заявляется. Скорость больших проектов зависит от памяти, видеокарты и используемых эффектов. Windows-пакеты пока не подписаны сертификатом издателя.
